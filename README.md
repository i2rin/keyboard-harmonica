# 鍵盤ハーモニカ展示デモ（表示画面＋タブレット操作）

## 会場で使う方法（インターネット不要）

表示用PCとタブレットを同じWi‑Fi（LAN）につなぎます。

1. 表示用PCに Node.js（v18以上）を入れておきます。
2. このフォルダで `node server.js` を実行します。
3. 起動すると、次のようなURLが表示されます。
   - 表示用PC（透過型ディスプレイ）: `http://localhost:8080/display.html`（`/#display` でも同じ）
   - タブレット: `http://<PCのIPアドレス>:8080/#controller`
4. 表示用PCの画面を一度クリックすると、音が出るようになります（ブラウザの決まりです）。
   Chromeをキオスクで起動する場合は `--autoplay-policy=no-user-gesture-required` を付けると、このクリックは不要になります。
5. 音は表示用PCのスピーカーから出ます。

ポートを変えるときは `PORT=9000 node server.js` のように実行します。
タブレットとの接続が切れると、2.5秒後に鳴りっぱなしの音を自動で止めます。

## 画面の種類

- `display.html`（または `#display`）… 透過型ディスプレイ用。ボタンは出ず、タブレットからの操作だけを受けます（キーボードの A〜K / 1〜8 でも鳴らせます）。
- `#controller` … タブレット用の操作パネル。
- ハッシュなし … 1台で完結する版（画面下にボタンあり）。

フォントはGoogle Fontsから読み込みます。ネットがない場合は端末内の日本語フォントで表示されます。

## 表示の調整（会場で使う）

表示画面で **P キー**（または右上の「調整」ボタン）を押すと、調整パネルが開きます。Esc で閉じます。

- **枠の濃さ**: 本体・鍵盤の濃さを 0〜200% で変えられます。下げるとリードがよく見え、上げると枠がはっきりします。
- **大きさ**: 楽器・タイトル・音名をまとめて 50〜150% に拡大縮小します。キーボードの ＋／− で 1% ずつ変えられます。
- **上下の位置**: 楽器・タイトル・音名をまとめて上下に動かします。キーボードの ↑↓ で 0.1cm ずつ、Shift+↑↓ で 1cm ずつ動かせます（表示画面の初期値は 3cm 下）。
- **台形補正（縦・横）**: 画面全体を台形にゆがめて、斜めから見たときや斜めに設置したときのゆがみを補正します。縦をプラスにすると上辺が狭く、横をプラスにすると左辺が短くなります。
- 設定は、そのPCのブラウザに記憶されます。「初期値に戻す」でリセットできます。
